    Methodology

    Satellite Imagery Acquisition

    Multispectral satellite imagery is acquired from LANDSAT and Sentinel-2 archives covering Nepal's administrative districts at 10–30 m resolution.

    Python Analysis Pipeline

    Imagery is processed through a Python pipeline using rasterio, GDAL, and scikit-learn to extract spectral indices and classify land cover types.

    QGIS Workflow

    QGIS is used for spatial preprocessing, coordinate system standardisation, and manual validation of automated classifications.

    GeoJSON Generation

    Processed spatial layers are exported to GeoJSON format using GDAL's ogr2ogr utility, optimised for browser-based Leaflet.js rendering.

    Data Cleaning

    Outlier detection and gap-filling methods are applied to annual forest cover time series to ensure temporal consistency across all 77 districts.

    Trend Analysis

    Linear regression and Mann-Kendall trend tests are applied to detect statistically significant forest cover change at district and provincial level.

    Prediction Model Architecture

    A gradient-boosted decision tree ensemble (XGBoost) is trained on 10-year historical data to forecast district-level forest cover through 2030, outputting risk scores and confidence intervals.

    Known Limitations

    Cloud cover during monsoon season reduces imagery availability for some districts. Prediction accuracy degrades for years beyond the 5-year forecast horizon.
